# Swatismita Parija — Professional Portfolio

A professional multi-page portfolio website built for **WeIntern Week 1 – Task 1: Professional Portfolio Website**.

## Objective

Present a web developer profile with clear information architecture, semantic HTML5, maintainable CSS, responsive layouts, accessibility improvements, and light JavaScript interactions.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- CSS Grid
- Responsive design
- Git / GitHub

No external UI framework or CSS library is required.

## Pages

- `index.html` — Home / hero / featured project
- `about.html` — Profile and experience
- `skills.html` — Technical skills and certifications
- `projects.html` — Project showcase with category filtering
- `resume.html` — Resume summary and PDF download
- `contact.html` — Contact information and validated demo form

## Features

- Semantic HTML structure
- Responsive desktop/tablet/mobile layout
- Flexbox and CSS Grid
- Consistent design system
- Dark/light mode toggle
- Mobile navigation
- Scroll reveal animation
- Project filtering
- Resume PDF download/open
- Accessible labels and focus states
- Skip-to-content link
- HTML form validation
- Reduced-motion support
- Reusable CSS classes
- Clean folder structure

## Run Locally

Because this is a static website, it can be opened directly in a browser.

For a better development workflow, use VS Code with Live Server or any local static server.

Example:

```bash
python -m http.server 5500
```

Then open:

`http://localhost:5500`
