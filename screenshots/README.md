# Required Portfolio Screenshots

The Week 1 handbook requires these screenshots for Task 1:

1. `portfolio-home-desktop.png` — full desktop home page
2. `portfolio-home-mobile.png` — mobile homepage
3. `portfolio-projects.png` — projects section/page
4. `portfolio-contact.png` — contact page/form

## Capture standards

- Use full-resolution captures.
- Crop unnecessary browser/desktop clutter.
- Keep text readable.
- Capture both desktop and mobile states where required.
- Use the exact filenames above.
- Review the screenshots before pushing to GitHub.

These files are intentionally not generated automatically because final screenshots should represent the actual browser-rendered deployment you submit.
